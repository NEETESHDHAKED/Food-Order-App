# 🍔 Food Order App

Order Food Online - Flask Web App with Cart, Checkout & Admin Panel.

## 🚀 Features
- Browse Food Menu with Images & Price
- Add to Cart / Remove from Cart
- Checkout & Order Placement
- User Login / Register
- Admin Panel - Add / Delete Food Items
- Order History

## 🛠️ Tech Stack
- Python
- Flask
- SQLite
- HTML, CSS, Bootstrap
- SQLAlchemy
